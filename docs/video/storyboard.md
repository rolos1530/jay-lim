## 3. 소재 수집 체크리스트

- [ ] 사진 15~20장 (섹션별 3~4장)
- [ ] 짧은 실제 영상 5~8개 (각 5~15초, 웃음소리 있는 것 우선)
- [ ] 성장·취향 사실 5개 (퀴즈 정답 근거)
- [ ] AI 변환용 정면·밝은 사진 2~3장
- [ ] 부모님 메시지 녹음 또는 자막 문구
- [ ] 배경음악 1~2곡
