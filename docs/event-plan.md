# 유주 돌잔치 가족 이벤트 계획 (검토 반영본)

콘셉트: **〈유주 인생 1년 차 — 이렇게 자랐어요!〉**
형식: 성장 영상 → 유주 퀴즈 → 유주 게임 → 시상·사진, 가족 10명, 약 15분

> 원안 대비 바뀐 부분은 각 항목에 **[수정]** 으로 표시했어요.

---

## 1. 진행 순서

| 순서 | 시간 | 내용 |
|---|---|---|
| (사전) 접속 | 식사 중 | **[수정]** QR 접속·이름 입력을 식사 시간에 미리 끝내기 |
| 안내 | 1분 | 진행 방식 안내, "영상에 퀴즈 정답이 숨어 있어요!" |
| 성장 영상 | 3~4분 | 실제 성장 기록 + 짧은 AI 장면 |
| 유주 퀴즈 | 4분 | 연습 1문제 + 본문제 5개 |
| 유주 게임 | 3분 | 설명, 10초 연습, 30초 공식 경기 |
| 시상·사진 | 2분 | 퀴즈왕·게임왕 시상, 기념사진 |
| 여유 | 1~2분 | **[수정]** 전환·접속 문제 대비 버퍼 |

- **[수정] 버퍼 확보**: 원안은 합계가 15~16분으로 여유가 0이에요. 어르신 접속에서 시간이 가장 많이 새므로, 접속은 식사 중 도우미 가족이 테이블을 돌며 미리 끝내요.
- **[수정] 배치 시점**: 돌잡이·식사 후, **유주 낮잠·수유 시간을 피해서** 배치해요. 시상·사진에는 유주가 있어야 하니 컨디션 좋은 시간대가 핵심이에요.

## 2. 성장 영상

구성(오프닝 → 성장 과정 → 취향 소개 → 가족과의 순간 → 엔딩)은 그대로 좋아요.

- **[수정] AI 장면은 "실사 얼굴 영상화"보다 "일러스트/캐릭터화" 우선 검토**
  - 아기 사진을 영상으로 움직이면 얼굴이 미묘하게 달라지기 쉽고(가족이 바로 알아챔), 일부 서비스는 실존 아동 이미지 생성을 제한해요.
  - 안전한 순서: ① 사진 → 일러스트 스타일 이미지(셰프 유주, 탐험가 유주) ② 실제 사진 누끼 + AI 배경 합성 ③ 그래도 만족스러우면 실사 image-to-video.
- **[수정] 아이 사진 업로드 전 확인**: 사용 서비스의 데이터 보관·학습 활용 정책(옵트아웃 가능 여부)을 확인하고, 필요한 사진만 올려요.
- **[수정] 도구는 하나만 먼저 검증**: Runway는 아직 연결 확인 전이에요. 샘플 1장으로 2~3개 서비스를 비교해 하나로 정하는 게 시간을 아껴요.
- 엔딩 20~30초는 실제 웃음소리 + 부모님 메시지 — 원안 그대로 유지.

## 3. 유주 퀴즈

- 퀴즈를 먼저 정하고 영상에 힌트 삽입 — 원안 그대로 핵심.
- **[수정] 동점 대비를 숫자 맞히기로**: 10명이 쉬운 5문제를 풀면 만점 동점이 많이 나와요. 추가 문제는 "유주 출생 몸무게는? (가장 가까운 사람 승)" 같은 **근삿값 문제**로 하면 한 번에 결정돼요.
- **[수정] 정답이 AI 장면에만 나오지 않게**: 모든 정답은 실제 사진·영상 + 큰 자막으로 제시해요.
- 결제 전 확인: 무료 요금제의 동시 참가 인원 제한(10명 이상), 문항 수, 점수 방식, 순위표.

## 4. 유주 게임 〈유주 웃음 모으기〉

원안 규칙(10초 연습, 30초 1판, 같은 등장 패턴, 1회 등장 1득점, 공동 1위 결승) 유지.

- **[수정] 공정성 구현 방식**: 등장 순서·위치를 고정 시드로 모두 같게, 시간 측정은 각 휴대폰에서 하고 끝난 뒤 점수만 전송 → 와이파이 지연이 점수에 영향 없음.
- **[수정] 퀴즈와 게임을 한 페이지로 합치는 안 검토**: 게임 서버를 어차피 만든다면 퀴즈도 같이 넣으면 QR 1개·이름 1번 입력·순위표 1개로 끝나고, 외부 퀴즈 서비스 결제·이름 불일치 문제가 사라져요. (원안처럼 AhaSlides를 쓰는 것도 충분히 가능하니 준비 여력에 따라 선택)

## 5. 상품·현장 운영

- 퀴즈왕·게임왕 각 1명, 1인 1상품 원칙 — 원안 유지.
- **[수정] 참가 기념품(선택)**: 아이·어르신 등 수상 못 한 가족을 위해 유주 사진 스티커/엽서 같은 작은 기념품을 전원에게.
- **[수정] 행사장 사전 확인을 "지금" 단계로**: TV/프로젝터 유무, 연결 단자(HDMI), USB 재생 가능 포맷(MP4), 와이파이, 스피커. 장소마다 달라서 일찍 확인할수록 좋아요.
- 오프라인 대비(영상 파일 로컬 보관, 손가락 퀴즈, 공용 기기 게임) — 원안 유지.

## 6. 준비 일정

| 시점 | 할 일 |
|---|---|
| 지금 | 사진·영상 선정, 퀴즈 소재 5개 + 근삿값 동점 문제, AI 샘플 테스트, **행사장 장비 확인** |
| 4~6주 전 | 영상 대본·스토리보드 확정, AI 장면 제작, 게임 시제품 |
| 2~3주 전 | 영상 편집, 퀴즈 입력, 상품·규칙 확정 |
| 1주 전 | 가족 2~3명 리허설(**어르신 1명 포함**), 최종 수정 |
| 당일 | 화면·음향·인터넷 확인, 점수 초기화, QR 배치, 식사 중 사전 접속 |

> 행사 날짜에 따라 일정은 압축이 필요할 수 있어요.
