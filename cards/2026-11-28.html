print와 return,
뭐가 다를까?

둘 다 "결과를 내놓는" 것처럼 보이지만, 하나는 보여주기만 하고 하나는 값을 돌려줍니다.

옆으로 넘기거나 → 키를 누르세요

02 / 06 · 개념

함수의 결과는
return으로만 받는다

return 값은 함수를 끝내면서 그 값을 호출한 자리로 돌려보냅니다. 그래서 y = add(2, 3)처럼 변수에 담거나, 다른 계산에 바로 쓸 수 있어요.

print()는 값을 화면(콘솔)에 출력할 뿐이고, 함수 밖으로는 아무것도 전달하지 않습니다.

핵심 한 줄

return이 없는 함수는 자동으로 None을 돌려준다.

03 / 06 · 비유

자판기로 생각해 보면

print

음료 사진만 화면에 띄워 줘요. 보이긴 하지만 마실 수는 없죠.

return

음료가 실제로 나와서 손에 쥐어져요. 마시든 친구 주든 마음대로.

함수 결과를 다음 코드에서 써야 한다면 무조건 return입니다.

04 / 06 · 코드 예제

직접 비교해 보기

def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

x = add_print(2, 3)   # 화면: 5
y = add_return(2, 3)  # 화면: (없음)

print(x)       # None
print(y)       # 5
print(y * 10)  # 50

add_print는 5를 보여줬지만, x에 남은 건 None뿐이에요.

05 / 06 · 흔한 실수

이런 실수, 한 번쯤 해요

  • print 결과로 계산하기값이 None이라 에러가 납니다. 
    total = add_print(2, 3) * 10
TypeError: unsupported operand type(s)
for *: 'NoneType' and 'int'
  • return 아래에 코드 쓰기return을 만나면 함수가 즉시 끝나서, 그 아래 줄은 실행되지 않아요.
  • 반복문 안에서 return첫 바퀴에서 바로 함수가 끝납니다. 다 모으려면 리스트에 담고 반복문이 끝난 뒤 return하세요.
06 / 06 · 퀴즈

출력 결과는?

def double(n):
    print(n * 2)

result = double(4)
print(result)

정답은 B. double(4)가 실행되며 화면에 8이 찍히고, return이 없으니 result에는 None이 들어가요. 그래서 두 번째 줄에 None이 출력됩니다.
