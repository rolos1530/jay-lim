8장 · 보전성

CRE 시험 마지막 단원(Maintainability & availability)을 8번의 짧은 활동으로 익혀요. 고장 나도 빨리 고치고, 고장 나기 전에 손보는 법을 배워요.

0 / 8 차시 완료

같은 기계, 다른 정비 일지

닳아서 고장 나는(마모형, 와이블 β = 3) 베어링 4개를 쓰는 기계의 1년이에요. 정비 전략을 바꾸면 갑작스런 고장 정지(빨강)와 계획 정지(노랑)가 어떻게 달라지는지 보세요.

예시 시뮬레이션이에요. 베어링 수명은 η = 2,500시간인 와이블 분포에서 뽑았고, 고장 정지는 24시간, 계획 정지는 4시간으로 가정했어요.

8장 학습 지도

순서대로 해도 좋고, 궁금한 차시부터 골라도 좋아요. 확인 문제를 모두 맞히면 초록 동그라미가 돼요.

8장 단원 평가

차시 확인 문제와 기출 문제를 섞었어요. 틀린 문제는 오답 노트에 자동으로 모여요.

오답 노트

틀렸던 문제와 해설이에요. 다시 풀어서 맞히면 노트에서 빠져요.

“CRE 첫걸음 공부방”의 보전성(BOK Ⅴ.C) 내용을 더 깊게 풀어 쓴 학습 앱이에요. 단원 평가에는 올려 주신 기출 노트(Ⅸ Maintainability, 답안지, 2번 파일)의 문제가 들어 있고, 오답 보기는 일부 새로 만들었어요. 진도와 오답 기록은 이 브라우저에만 저장돼요.
